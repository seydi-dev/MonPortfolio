VigiTech — SaaS Sécurité

Plateforme SaaS de gestion des rondes de sécurité, en production sur 5 sites actifs. Les agents font leurs rondes sur une application Android avec des tags NFC. Les gestionnaires suivent tout sur un tableau de bord web.

  • Application Android : choix de la ronde, scan des tags NFC, signalement des incidents
  • Tableau de bord Angular : rondes effectuées, taux de complétion, durée moyenne, incidents et activité des agents
  • Alertes sur les zones non visitées depuis plus de 24 h ou 48 h
  • Export des rapports, signature électronique, mode sombre
  • Backend Spring Boot 3, JWT et RBAC, PostgreSQL, déploiement AWS avec Docker et GitHub Actions
